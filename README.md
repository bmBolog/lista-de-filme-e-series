# API de Filmes e Séries 🎬

Projeto feito com **Node.js** e **Express** para gerenciar filmes e séries.

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor:
   ```bash
   node index.js
   ```

Servidor disponível em:  
**http://localhost:3000**

---

## Rotas

### Filmes
- `GET /filmes` → Lista todos os filmes  
- `GET /filmes/:id` → Busca filme pelo ID  
- `POST /filmes` → Cria um novo filme  

### Séries
- `GET /series` → Lista todas as séries  
- `GET /series/:id` → Busca série pelo ID  
- `POST /series` → Cria uma nova série  

---

## Observações
- Os dados ficam em arrays na memória (`filmes` e `series`).  
- Não há banco de dados conectado.
